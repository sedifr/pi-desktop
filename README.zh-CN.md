# Pi Desktop

[English](./README.md)

[pi 编程 Agent](https://github.com/earendil-works/pi) 的非官方桌面端。它和 pi 用同一份本地配置和会话文件，所以对话、模型、技能、MCP 服务都和 pi 命令行共用。

> 状态：早期版本。只支持 macOS。还没有安装包，需要从源码运行。

## 能做什么

- **按项目管理对话**：本机所有 pi 会话，按项目文件夹归类。
- **干净的输入栏**：输入框里只留写消息要用的：「+」菜单、模型和发送。下面那一行说在哪个项目里、pi 能做到哪一步。技能、MCP、工具和插件市场在聊天区左边一小列图标里，一个图标一个功能。
- **看得见它在干活**：思考内容实时滚动，正在跑的工具显示最新输出，底部一行写着现在在做什么、用了多久——分得清是在想还是卡住了。
- **快捷指令**：打 `/` 选指令——你自己存的话、技能、扩展带的命令，每条都有一句简介。在「设置 → 快捷指令」里写和改自己的指令；它们存成 pi 的提示词模板，命令行里也能用。
- **文件和图片**：打 `@` 引用项目里的文件。粘贴或拖入图片就是附件。
- **权限档位**：一个开关切换「只读」「可改文件」「完全访问」。
- **边做边指挥**：回答进行中再发消息，会插到当前这一步之后；按住 Option 发送则等全部做完再处理。
- **另开和整理**：从之前任意一条消息另开一个对话，给对话改名，复制回答，压缩上下文，把对话导出成网页。
- **自己运行命令**：消息以 `!` 开头就是直接运行一条命令，输出显示在对话里，下一条消息会带给 pi。用 `!!` 则只给自己看。
- **排队和撤回**：回答进行中发出的消息会排队，可以撤回到输入框。停止回答时排队的消息也一起退回。
- **上下文看得见管得住**：自动压缩的开关、「现在压缩」按钮，上下文快满时有提示。
- **看得开**：对话正文跟着窗口宽度走（「设置 → 外观 → 对话区宽度」：标准、宽、铺满）。代码按语言上色，带复制按钮；`⌘F` 在当前对话里查找；往上翻了之后有按钮一下回到最新。
- **可以反悔**：已经发出去的消息可以改了再发，对话从那里接着走；最后一个回答可以重新生成。被换掉的那几轮还留在会话文件里，是另一条分支（pi 的 `/tree` 能回去）。鼠标停在消息上能看到是几点发的；自己发的图片点一下能放大。
- **自动起标题**（可选，在「设置 → 通用」）：聊完第一轮后让模型把对话概括成几个字，每次大约 150 个 token。默认关着；可以用对话自己的模型，也可以指定一个便宜的。
- **可以多开窗口**：`⌘⇧N` 再开一个窗口，每个窗口看自己的对话；同一个对话在两个窗口里都开着时两边实时同步，背后只有一个 pi 进程。
- **顺手的小地方**：右键可以复制粘贴；窗口下次打开还在原来的位置和大小；没发出去的草稿重启后还在；输入框空着时按 `↑` 找回上一条；回答出错时用人话说明原因，点一下就能再试；还有对话在回答时退出会先问一句。
- **找对话**：`⌘K` 按标题、项目名和对话里说过的话搜索，多个词一起搜能缩小范围；打开结果会直接滚到对上的那条消息。什么都不输入时列出最近的对话，可以当快速切换用。
- **整理对话**：常用的对话可以置顶（一直排在侧栏最上面，置顶的几个可以拖动排顺序）；开错项目的对话，拖到另一个项目上就移过去了；双击对话改名；这些操作右键菜单里都有。移过去的对话以后在新项目的文件夹里接着做，pi 命令行里也归到那个项目下；它已经写好的文件不动。
- **逐段回复**：在回答里选中一段文字，点「引用」，它就成了输入框里一个带底色的框，下面是这一段自己的回复栏。可以接着引用别的段落，逐段写回复，一次发出去。引用的原文不会被误改，只能整段移除。
- **附上文档**：PDF、Word、PPT、Excel 在附上的时候（「+」菜单、拖进来、`@`、文件页都算）会先提取出文字，pi 读的是这份文字。不用另外装任何工具，只读权限下也能用，pi 用到多少读多少。扫描的 PDF 没有文字可提取，会把前几页当图片附上，交给能看图的模型。其他文件还是按路径交给 pi。
- **插件市场**：「设置 → 插件」浏览 pi 的包目录（npm 上带 `pi-package` 标记的包，和 pi.dev/packages 是同一批）：按最常用排、按类别看、或者搜索，点一下就能装。目录里的包没有人审核，页面上写明了这一点，安装前会先问一句。
- **看项目里的文件**：右侧面板的「文件」页显示这个对话所在的文件夹和里面的所有东西。点一个文件（或者把它拖进聊天窗口）就把它 `@` 进输入框；可以按名字搜，也可以打开或在访达里显示。
- **把一个对话交给另一个对话**：从侧栏把对话拖进聊天窗口，它就成了 pi 可以读的参考。交给 pi 的是一份只有文字的记录（双方说的话、每次工具调用一行，不带大段工具输出和图片），用到多少读多少，不用吞下整个原始会话文件。右键菜单还能复制这份文字记录的路径、会话文件的路径或对话 ID，方便交给别的 AI。
- **长什么样自己定**：界面只是 pi 的一层外壳，不预设任何风格。「设置 → 外观」里可以铺一张自己的背景图、挑强调色、给底色染一点色调（也可以让配色跟着图走）；界面上每个部件——侧栏的入口、聊天区旁边的图标、标题栏和输入框上的按钮、右侧面板的页签——都能在「设置 → 布局」里单独藏起来，对话列表和图标列可以换到右边。还不够的话，可以把每个颜色写进一个配色文件，或者自己写一份 CSS 接在自带样式后面。这些都只改外观：菜单、输入框、卡片有自己的底色，图不会透过去；图和主题明暗差得多时会自动少露一些，挑的颜色太浅太深会自动调到认得清；菜单栏「显示 → 恢复默认外观」一下回到原样。
- **自己的按钮**：界面上划了六个位置——输入框上方、输入框里、聊天区旁边那列图标、标题栏、侧栏、新对话的空白页——你可以往里面放自己的按钮。一个按钮可以是一句常说的话（或一条快捷指令、一个技能，直接发出去或先放进输入框）、一条直接运行的命令、一个要打开的网址或文件、界面上现成的一个功能（终端、搜索、压缩上下文、最精简……），或者一下切到某个模型、推理档位、权限档位。在「设置 → 布局」或输入框的「+」菜单里加，右键按钮就能改。默认一个都没有。
- **让 pi 来改界面**：按钮（`buttons.json`）、样式（`custom.css`）、配色（`skins/*.json`）都是普通文件，应用盯着它们，谁改了都当场生效，不用重启。所以可以直接对 pi 说「在输入框上方加一个按钮，点了就……」「把圆角改方一点」：「设置 → 布局 → 让 Pi 来改」会开一个新对话，并把写给 pi 看的说明（`CUSTOMIZE.md`）交给它。写错的按钮会被跳过并在设置里报出来，不会拖垮界面。
- **做完会提醒**：窗口在后台时回答做完会发系统通知；不在眼前的对话做完了，侧栏会有一个点。
- **MCP 服务**：在「设置 → MCP」里添加、修改、删除，看每个服务连不连得上，要授权的远程服务可以直接点「登录」（会在浏览器里打开授权页面），并决定每个服务的工具怎么交给模型（用到时再找、写脚本调用，或者全部直接给）。环境变量和请求头里的密钥不会回显。装了 `pi-mcp-adapter` 扩展的话，同一页可以在它和 pi 自带的 MCP 之间切换。
- **用你自己的话**：每个技能、MCP 服务、工具都有一句简介，可以直接在卡片上改写，方便自己记住它是干什么的。还没有简介的项，可以点一下让模型各写一句。
- **安装技能**：「设置 → 插件 → 已安装」里安装和移除 pi 的包（npm、git 或本机文件夹），和 `pi install` 是一回事；也可以在这里添加额外的技能文件夹。
- **右侧面板**：对话旁边一个带页签的面板——「文件」（见上）、「改动」（项目里没提交的改动，标出 pi 动过的文件，点开看每个文件改了什么）、「浏览器」（一个小的内置浏览器，看本机跑起来的页面；回答里的 localhost 链接会在这里打开）、「终端」（项目文件夹里一个真正的终端）。
- **图片集中管理**：「图片」页列出所有对话、所有项目里生成过的图片——浏览、搜索、回到生成它的对话、复制、另存，或者成批移到废纸篓。回答里按本机路径提到的图片会直接显示出来。
- **看得到子代理**：AI 开了子代理时，标题旁会出现一个标签列出它们；点开能看它做了什么，再一键回到主对话。
- **决定一次对话能用什么**：每个技能、MCP 服务、工具都可以按对话开关，然后存成项目默认或全局默认。技能有三档：「自动」（模型自己判断要不要用）、「开」（一定带上）、「关」（模型看不到）。「最精简」一键全部关掉，对话开场几乎只带 pi 本身；需要什么再打开，也可以把这个状态存成默认。
- **用量一眼可见**：本次对话的费用、token、缓存命中率、上下文占比，以及今天和本月的合计。
- **模型**：订阅账号登录、填 API Key、添加 OpenAI 或 Anthropic 兼容的接口。每个提供商前面的圆点显示登录是否还有效。模型菜单可以搜索，常用的模型可以加星标排到最前。

## 环境要求

- macOS
- Node.js 22.19 或更新
- 不需要别的。应用自带一份 pi，不用另外安装 pi 命令行。

## 从源码运行

```bash
git clone https://github.com/sedifr/pi-desktop.git
cd pi-desktop
npm install
npm run build
npx electron .
```

开发时带热更新运行：

```bash
npm run dev
```

## 打包成应用

```bash
npm run pack
```

会在 `release/mac-arm64/` 里得到 `Pi Desktop.app`。`npm run dist` 另外再出一个 `.dmg` 和一个 `.zip`。

- 应用只做了本机签名（背后没有 Apple 的开发者证书）。在自己电脑上直接能用；拿到别人的 Mac 上，第一次要右键点它选「打开」。
- 同样的原因，它没法自己更新。「设置 → 关于 → 检查更新」会告诉你有没有新版本，并带你去下载页。
- 项目要是放在 iCloud 云盘同步的文件夹里（桌面和文稿常常是），签名会因为同步加上的文件属性而失败。换个地方打包：`npm run pack -- -c.directories.output=/tmp/pi-desktop-release`。

## 第一次使用

1. **添加项目文件夹。** 点侧栏「项目」旁边的 `+`，选择要让 pi 工作的文件夹。
2. **连接模型。** 打开「设置 → 模型」，选一个提供商，登录或者粘贴 API Key。出现绿点就是可用。
3. **开始对话。** 在底部输入框里打字，按回车发送。Shift+回车换行。
4. **选择技能和工具。** 点聊天区左边那列里的图标（技能、MCP、工具）。改动只影响当前对话，从下一条消息起生效。
5. **把反复要说的话存下来。** 打开「设置 → 快捷指令」，写一次，以后用 `/名字` 调出来。

### 项目信任

pi 只在你信任一个文件夹之后，才加载它自带的配置（`.pi/skills`、`.pi/prompts`、`.pi/extensions`、`.pi/mcp.json` 等）。项目里有这些文件、又没有存过决定时，输入框上方会出现提示。点「信任并加载」会把决定记到 pi 的 `~/.pi/agent/trust.json`，和命令行用的是同一份。之后可以在标题栏的 `···` 菜单里改。项目里的扩展能在你的电脑上运行代码，所以只信任你清楚来源的项目。

### 快捷键

| 按键 | 作用 |
|---|---|
| `⌘N` | 新对话 |
| `⌘⇧N` | 新窗口 |
| `⌘O` | 添加项目文件夹 |
| `⌘,` | 设置 |
| `⌘K` | 搜索对话 |
| `⌘F` | 在当前对话里查找 |
| `⌘B` | 显示或隐藏侧栏 |
| `⌥⌘B` | 显示或隐藏右侧面板 |
| `⌘/` | 打开快捷指令 |
| `⌘⇧M` | 切换模型 |
| `⌘⇧C` | 复制上一条回答 |
| `⌘.` 或 `Esc` | 停止正在进行的回答 |
| `Enter` / `⇧Enter` | 发送 / 换行 |
| 开头打 `!` / `!!` | 直接运行命令（输出带给 / 不带给 pi） |
| `⌥Enter` | 正在回答时：等全部做完再处理这条 |

如果你已经在用 pi 命令行，原有的会话、模型、技能和 MCP 服务会直接出现。

## 数据存在哪

| 内容 | 位置 |
|---|---|
| 会话、登录凭证、模型、技能、MCP 配置 | pi 自己的目录 `~/.pi/agent/` |
| 快捷指令（提示词模板） | `~/.pi/agent/prompts/`，或项目里的 `.pi/prompts/` |
| 项目信任的决定 | `~/.pi/agent/trust.json` |
| MCP 服务 | `~/.pi/agent/mcp.json` |
| 技能、MCP、工具的开关 | `~/.pi/agent/desktop/capabilities.json` |
| 界面上显示的一句话简介 | `~/.pi/agent/desktop/summaries.json` |
| 应用设置 | `~/.pi/agent/desktop/config.json` |
| 只在本应用里加载的扩展 | `~/.pi/agent/desktop/extensions/` |
| 背景图（拷进来的那一份） | `~/.pi/agent/desktop/wallpaper/` |
| 自己的配色文件 | `~/.pi/agent/desktop/skins/*.json` |
| 自己写的样式 | `~/.pi/agent/desktop/custom.css` |
| 自己的按钮 | `~/.pi/agent/desktop/buttons.json` |
| 给 pi 看的「怎么改界面」的说明（每次用到时重新生成） | `~/.pi/agent/desktop/CUSTOMIZE.md` |

应用里的开关不会改 pi 自己的 `settings.json`，所以不影响命令行。登录和添加模型会改 pi 的 `auth.json` 和 `models.json`，因为这两份是共用的。

### 给出图工具的作者

工具结果的 `details.path` 里写着图片存到了哪（`details.prompt` 里可以带上生成要求），「图片」页就能找到这张图。用户指定了统一存图的文件夹时，应用会通过环境变量 `PI_DESKTOP_IMAGE_DIR` 告诉 pi，设置了就请存到那里。

## 工作原理

每个对话背后是一个 `pi --mode rpc` 子进程。应用通过 pi 的 JSON 协议和它通信，并把开关翻译成 pi 的启动参数。登录和模型管理用的是 pi 的 SDK。

自带的 pi 版本写死在 `package.json` 里。要换成更新的 pi：改版本号，运行 `npm install`，再确认对话还能正常进行。

界面有简体中文和英文两种语言（「设置 → 通用」）。

## 已知限制

- 只支持 macOS，Windows 和 Linux 没有测过。
- 打包出来的应用没有经过 Apple 公证，所以不能自己更新，在别人的 Mac 上第一次打开要确认一下。
- 按对话开关 MCP 服务依赖 `pi-mcp-adapter` 扩展，它会把所有工具的说明提前交给模型，所以每次对话都占 token。pi 自带的 MCP 用到时才找工具，几乎不占，但服务对所有对话都一样。
- 在某次对话里关掉一个扩展时，pi 会带着应用认得的那些扩展重新启动。只写在项目 `.pi/settings.json` 里的包，这种情况下不会被带上。
- 远程 MCP 服务的登录用的是 pi 自带的 MCP。需要预先注册登录客户端的服务，要手动在 `mcp.json` 里配。
