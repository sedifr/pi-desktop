# Code of Conduct

This is a small project and the rule is simple: be decent to each other.

- Assume the other person means well, and say what you mean plainly.
- Criticize code and ideas, not people.
- No harassment, no insults, no discrimination of any kind.
- Respect that maintainers have limited time; a "no" to a feature is not a judgment of you.

If someone's behavior in an issue, pull request or discussion crosses a line, report it privately through the repository's Security tab ([Report a vulnerability](https://github.com/sedifr/pi-desktop/security/advisories/new) is a private channel to the maintainer) and say it is a conduct report. Comments may be edited or removed, and people who keep at it may be blocked from the repository.
